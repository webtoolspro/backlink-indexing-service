## Important claim policy

The website does not claim that a search engine will index 100% of submitted backlinks. Search-engine indexing decisions are controlled by the relevant search engine. The site's 100% messaging refers to submission/service coverage rather than a guaranteed search-engine indexing outcome.

## Files

- `index.html` - page structure, enquiry form and pricing
- `styles.css` - main responsive visual system
- `custom.css` - enquiry, WhatsApp and five-plan pricing styles
- `script.js` - WhatsApp enquiry generation and plan selection

## Deploy with GitHub Pages

1. Open repository Settings.
2. Go to Pages.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

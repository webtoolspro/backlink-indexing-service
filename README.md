# IndexPilot

Professional backlink indexing service website built as a fast, responsive static site.

## Included

- Modern SEO-focused landing page
- Responsive navigation and mobile layout
- Hero dashboard visualization
- How-it-works workflow
- Feature section
- URL submission demo with client-side validation
- Pricing cards
- FAQ section
- Accessible semantic HTML
- Responsive CSS with no framework dependency

## Important

The current URL submission form is intentionally a front-end demo. It validates URLs in the browser but does not claim to submit them to Google or another search engine. A production service should connect this form to a secure backend and a legitimate indexing/submission provider.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual system
- `script.js` - URL validation and demo submission interaction

## Deploy with GitHub Pages

1. Open the repository settings.
2. Go to **Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.
